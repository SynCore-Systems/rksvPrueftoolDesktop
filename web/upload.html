    Über dieses Tool

    Was ist RKSV Prüftool?

    RKSV Prüftool ist eine Desktop-Anwendung, die den Zugang zu den offiziellen Validierungswerkzeugen des Bundesministeriums für Finanzen (BMF) Österreich vereinfacht. Dieses Tool führt selbst keine Validierung durch, sondern nutzt die zertifizierten BMF-Validierungsbibliotheken zur Überprüfung von DEP-Exporten und QR-Code-Belegen nach der österreichischen Registrierkassen-Sicherheitsverordnung (RKSV).

    Was macht dieses Interface?

    Dieses Tool bietet eine benutzerfreundliche Oberfläche für:

    • Einfaches Hochladen von DEP-Export und QR-Code Dateien
    • Verwaltung von kryptographischen Materialien (als Datei oder manuelle Eingabe)
    • Automatisches Starten der BMF-Validierungsprozesse
    • Übersichtliche Darstellung von Validierungsergebnissen
    • Download von detaillierten Prüfberichten und Logs
    • Verwaltung des Validierungsverlaufs

    Die tatsächliche Validierung

    Die eigentliche Validierung wird durchgeführt von den offiziellen BMF-RKSV-Validierungsbibliotheken:

    • DEP-Validierung: regkassen-verification-depformat-1.1.1.jar
    • QR-Code-Validierung: regkassen-verification-receipts-1.1.1.jar

    Diese Komponenten werden vom BMF-RKSV-Technik-Team entwickelt und gewartet. Dieses Interface dient nur als Wrapper zur vereinfachten Nutzung. Das Prüfmodul wird vom offiziellen GitHub-Release des BMF bezogen und vor der Verwendung anhand seiner SHA-256-Prüfsumme auf Unverändertheit geprüft.

    Technische Architektur

    Benutzeroberfläche:

    • HTML5 / CSS3 / JavaScript (Vanilla)
    • Angezeigt in einem Microsoft-Edge-WebView2-Fenster

    Programm:

    • Go, lokaler Dienst – nur auf diesem Rechner erreichbar
    • Mitgelieferte Java-8-Laufzeitumgebung (Eclipse Temurin), keine Java-Installation nötig

    Validierungs-Engine:

    • Java-basierte BMF-Validierungsbibliotheken
    • Ausführung: java -Xmx2g -Duser.timezone=<zeitzone> -jar regkassen-verification-*.jar -v -f -i <input> -c <crypto> -o <output>

    Alle geprüften Dateien und Validierungsergebnisse werden ausschließlich lokal auf diesem Rechner gespeichert (%LOCALAPPDATA%\SynCore\RKSV-Prueftool). Es werden keine Daten übertragen – mit Ausnahme des einmaligen Downloads des BMF-Prüfmoduls von GitHub. Die Daten können jederzeit gelöscht werden (siehe "Alle Daten löschen" im Verlauf-Tab). Die maximale Dateigröße beträgt 2 GB.
